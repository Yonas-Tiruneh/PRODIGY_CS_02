## PRODIGY_CS_02:Image Encryption
   This project is a simple python based tool for image encryption and decryption. it allows a users input an image file and a secret key to secure their image
   
## Features 

  Encryption: secure your image by using a secret key
  
  Decryption: retrive the orginal image by using a key
  
  User-friendly : Simple to use
  
## How to use 

  Ensure you have Python installed on your system.
  
  Clone this repository.
  
  Run the script using the command: python main.py
  
  Follow the on-screen instructions to select the mode (Encrypt/Decrypt) and enter your inputs.
